# knitcell

Knit numeric cell values, ranges, and human-readable units.

**Site:** https://theworker02.github.io/knitcell/

## Install / run

```bash
git clone https://github.com/theworker02/knitcell.git
cd knitcell
node src/cli.js
node --test
```
